ℹ️ VTU CBCS Grading System

VTU SGPA Formula

SGPA = Σ(Credits × Grade Points) / Σ(Credits)

VTU CGPA Formula

CGPA = Σ(Semester Credits × SGPA) / Σ(Semester Credits). If credits are not entered, a simple average of the SGPAs is shown.

VTU Percentage Formula (Scheme-wise)

2014 / 2015 / 2017 / 2018 Scheme: Percentage = CGPA × 10

2021 / 2022 / 2023 / 2024 / 2025 Scheme: Percentage = (CGPA − 0.5) × 10

Grade Points

O = 10, A+ = 9, A = 8, B+ = 7, B = 6, C = 5, P = 4, F = 0

Class Awarded

First Class with Distinction: ≥ 70% • First Class: 60–69.9% • Second Class: 50–59.9% • Pass Class: 40–49.9%
